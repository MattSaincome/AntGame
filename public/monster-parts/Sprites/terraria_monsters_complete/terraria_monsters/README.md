# Terraria-Style Monster System

## Features
- High-quality pixel art (32x32 base, displayed at 64x64)
- 10 evolution stages per monster type
- Modular parts system
- Professional shading and highlights
- Smooth animations possible

## Current Monsters
1. **Dragon Line**: Baby drake → Elder dragon
   - Color progression from green to purple
   - Wings appear at stage 3
   - Horns grow with evolution
   - Size increases each stage

2. **Slime Line**: Blue slime → King slime  
   - Translucent effect
   - Internal bubbles and core
   - Crown at final evolution
   - Color shifts from blue to magenta

## Expansion Guide
To add more monsters:
1. Create modular parts at 32x32
2. Use the established color palette system
3. Follow the shading patterns (top-lit)
4. Save parts in appropriate folders
5. Test assembly at 64x64 display size

## Quality Standards
- Anti-aliased edges for smooth appearance
- Consistent light source (top-left)
- 8-color palettes per sprite
- Alpha channel for transparency effects
